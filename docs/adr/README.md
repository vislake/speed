# 架构决策记录

本目录记录 speed 的架构决策：每条记录说明当时面临的约束、考虑过的选项、采纳的结论以及为此付出的代价。

记录随发布冻结，合并不是分界。冻结之前可以自由修订：改写、改标题、改主题名、合并或拆分，并复查引用它的每一份文档。冻结之后变更一项决策的方式是写一条新记录取代旧记录，而非修改旧记录。

引用形式为 `ADR-<主题>-<日期>`。同一主题的多条记录共用主题名，按日期先后排列。
