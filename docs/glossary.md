# 术语表

本项目全部文档共用这一份术语表，它只收录在项目范围内处处成立的术语，已登记的术语在所有文档中用词一致。

通用技术词汇不登记。含义由某个模块界定的术语登记在该模块自己的文档里。

## 结构

| 术语 | 英文 | 定义 |
|---|---|---|
| 模块 | module | 向注册表登记一份描述符的单元：它参与生命周期，进出启用集，交付功能。注册单元不等于发布单元，见发布单元。 |
| 发布单元 | release unit | `pkg/` 下的一个独立 Go module，按功能划分，是版本与发布的粒度。一个发布单元登记零到多个模块，通常每个实现子包登记一个。 |
| 子包 | subpackage | 发布单元内部的一个目录。实现的拆分默认用子包，用于把第三方依赖隔离在使用它的那个包内；实现子包各自登记为一个模块。 |
| 接口包 | interface package | 发布单元的根包。它定义功能的接口与数据类型，也可含不引入第三方依赖的公共逻辑；绑定第三方库的实现一律位于子包。它通常不登记为模块，根包自身即实现的发布单元除外。 |
| 宿主 | host | 使用 speed 的应用程序：它编写 `main`，import 所需模块，驱动装配。 |

## 装配

| 术语 | 英文 | 定义 |
|---|---|---|
| 描述符 | descriptor | 模块向注册表登记的不可变声明：名称、构造期依赖、所交付的功能、对外资源与各阶段回调。 |
| 资源 | resource | 模块对外声明的只读元数据，`Run` 之前确定，供其他模块与注册表按类型查询。类型由需要它的模块定义，注册表不解释其含义。 |
| 注册表 | registry | 模块机制的本体。描述符部分在 `Run` 之前写入，此后不可变；实例部分由生命周期驱动逐阶段建立，随注册表实例各自持有。 |
| 可用集 | available set | 已登记到注册表的模块集合。进程级注册表的登记主要发生在 `init`，凡被 import 进来的模块包都会执行，因此它不限于宿主直接 import 的模块，也包含依赖间接 import 的。 |
| 启用集 | enabled set | 本次运行实际构造的模块集合：表态非禁用且未被消解禁用的模块，加上配置模块（若已登记）。必为可用集的子集。 |
| 阶段 | stage | 生命周期中的一个固定时机。阶段集合是模块作者与注册表之间的稳定契约。 |
| 功能 | capability | 模块之间相互取用的单位，以一个接口类型表达。声明与取用指代的都是功能，不是实例。 |
| 功能标识 | token | 功能在声明与取用中的写法：指向该功能接口的类型化空指针，例如 `(*Cache)(nil)`。 |
| 排他交付 | exclusive provision | 交付声明中的标注，表示本模块独占该功能。它是提供方对自身的声明，不是对该功能的全局断言；消解之后本模块仍然启用时，该功能若还有其他启用的提供者，即启动失败。被禁用的提供者不再主张独占。 |
| 构造期依赖 | construction dependency | 模块在描述符中声明的功能依赖，决定构造顺序，必须无环。相互引用不在此声明，改由接线阶段动态取得。 |

## 参数

| 术语 | 英文 | 定义 |
|---|---|---|
| 配置 | config | 启动所必须的参数。进程级，全局一份，启动时读取一次后不再变化，变更需重启。 |
| 设置 | settings | 运行期可变的参数，存放于数据库，可按租户取不同值。由独立模块承载，不属于配置。 |
