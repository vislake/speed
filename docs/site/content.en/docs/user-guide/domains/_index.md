# Domain guides

The fastest way into speed: each domain page walks one product need
end to end — which modules are involved, the minimal integration
steps, an example, and where to go next.

- [Identity and access](identity-access/) — sign-in, sessions and
  permissions (`authn`, `rbac`, `org`).
- [Tenancy and organizations](tenancy-and-org/) — tenant resolution
  and the organization tree.
- [Data and configuration](data-and-config/) — data models, the four
  data domains, dynamic configuration.
- [Billing and metering](billing-metering/) — usage metering,
  subscription plans, credits, compliance operations.
- [Jobs and notifications](jobs-and-notifications/) — background
  tasks and the messaging surface.
- [Storage, sharing and AI](storage-sharing-and-ai/) — object
  storage, public share links, the AI gateway.
- [Observability and operations](observability-and-ops/) — logging,
  metrics, tracing, error-code handling.
- [Building the frontend](frontend-building/) — composing the
  `@speed/*` npm packages.

For the complete per-module reference — every Go module and npm
package on its own page — see the [module reference](../modules/).
