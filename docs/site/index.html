speed

A modular monolith distributed as libraries: independently released Go modules and npm packages that business projects pull in via go get / npm install and compile into one binary.

On this site

  • About speed — what the project is, how the pieces fit, and how its documentation is distributed.
  • Status — where implementation stands, milestone by milestone.

This site is a skeleton. The pages here are static HTML with no build step, so they are previewable and checkable today — but the full machinery is a later milestone: per-version release directories, llms.txt once the site goes public, and the complete documentation set. What is real now versus deferred is spelled out on About and in the operating note at the top of this tree (docs/site/README.md, outside the site itself).
