# 开发者文档

开发 speed 本身:本栏面向**在 speed 上工作的开发者**——仓库自己的
工程师与任何扩展其模块的人。它解释总体架构、背后的设计原则,以及
每个模块为什么这样设计。

## 结构

- [**总体架构**](architecture/)——模块化单体、模块依赖方向、部署模
  式与实现组装两条正交轴、模块接线契约。
- [**设计原则**](design-principles/)——每个模块都遵守的纪律:模块
  边界、多租户隔离、先契约后代码的 API、异步工作、测试分层——以及
  背后的为什么。
- [**逐模块设计**](modules/)——每个 Go 模块与 npm 包各一页:模块
  职责与边界(包括它**明确不做**什么)、它长成这样的设计决策与取舍、
  关键机制,以及其中哪些是冻结的公开 API。该区按模块依赖顺序排列,
  从上往下读就是完整的设计叙事。
设计页从各模块自己的 `AGENTS.md` 提炼而来——每页都带 Source 小节
链回它,任何论断都能回到该模块随附的文档核验。
