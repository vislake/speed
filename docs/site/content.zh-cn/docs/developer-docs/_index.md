# 开发者文档

开发 speed 本身:本栏面向**在 speed 上工作的开发者**——仓库自己的
工程师与任何扩展其模块的人。它解释总体架构、背后的设计原则,以及
每个模块为什么这样设计。

## 结构

- **总体架构**——模块化单体、模块依赖方向、部署模式与实现组装两条
  正交轴、模块接线契约。
- **设计原则**——每个模块都遵守的纪律:模块边界、多租户隔离、先契
  约后代码的 API、异步工作、测试分层——以及背后的为什么。
- **逐模块设计**——每个 Go 模块与 npm 包各一页:模块职责与边界
  (包括它**明确不做**什么)、它长成这样的设计决策与取舍、关键机制,
  以及其中哪些是冻结的公开 API。左侧导航按模块依赖顺序排列,从上往
  下读就是完整的设计叙事。
- **实现状态**——实现当下真实走到哪;仓库根 CLAUDE.md 的 Repository
  Status 一节是权威事实源。

本栏页面随站点内容批次完成而陆续落地;左侧导航始终是当前的最新地图。

设计页从仓库内部设计文档(`docs/internal/`)与各模块 `AGENTS.md`
提炼而来——每页都带 Source 小节链回原文,任何论断都能回到底层文档
核验。
