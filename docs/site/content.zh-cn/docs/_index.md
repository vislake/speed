# 文档

speed 是一系列独立发布的 Go module 与 npm 包，不是一个应用程序。本节的
页面是面向业务方团队以及负责接入的 AI 编码 Agent 的中心参考。

- [快速开始](quickstart/) —— 用 `saasctl new` 生成一个起始项目、
  `saasctl` 的四个命令，以及如何在本仓库的 workspace 结构下运行 Go
  命令。
- [模块索引](modules/) —— 模块清单：每一个 `go/` module 与
  `web/packages/*` 包（以及 reference-app 的 web host），各自链接到
  自己的 `AGENTS.md`/`README.md`。
- [面向 AI Agent](ai-agents/) —— 明确的 AI Agent 入门指引：先读什么、
  最容易踩坑的架构纪律，以及权威的实现状态在哪里。
- [关于](about/) —— speed 是什么、它的文档如何分发。
- [实现状态](status/) —— 一份对照仓库核实过的粗粒度快照；指向仓库根
  CLAUDE.md 的 Repository Status 一节作为权威、当前的信息源，而不是
  重复它逐模块的细节。
