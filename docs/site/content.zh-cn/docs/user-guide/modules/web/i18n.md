# @speed/i18n

平台给 web 包用的 i18n 层:每个宿主一个包了 react-i18next 的实例、
协商出的起始语言、按包注册且带对等与覆盖校验的命名空间,以及一条
**绝不静默跨语言回退**的缺键纪律。它是 Go 侧 `pkgcore/i18n` 合并
目录的前端对应物——线两侧同一条规则:被问到的语言里缺键,绝不渲
染成另一种语言的文字。MUI locale 助手住在被隔离的
`@speed/i18n/mui-locale` 子路径里。

## 它做什么

浏览器宿主要做的每一个语言决定:

- **起始语言协商**——一条固定链,先中者胜:URL 参数(`?lang=...`)、
  持久化的手动选择、profile 语言槽(给能解析出登录用户 locale 的
  宿主用;它压过浏览器,但排在 URL 参数与持久化选择之后)、浏览器
  语言,最后落到 `en-US` 默认。子标签匹配双向放宽,但永不跨语言。
- **按包命名空间**——每个包一个裸的、不带作用域的命名空间
  (`ui-kit`、`auth-ui`……)。带 locale 资源的包以自己的基础名注
  册;你自己的应用资源同样注册。
- **注册时校验**——`registerNamespace` 在任何变更之前检查:每种
  受支持语言都必须齐全,所有资源束必须带**同一组叶子键**,叶子必
  须是非空字符串,复数族(`key_one`、`key_other`……)必须覆盖受支
  持语言能选出的每一种计数类别,且每个命名空间只注册一次。
- **缺键可见**——实例被钉成 `fallbackLng: false` 加
  `load: 'currentOnly'`:加载语言里缺的键渲染成键本身,并触发一个
  带结构的缺键处理器——默认可见,创建时可用 `onMissingKey` 覆盖。

它不是翻译管理系统,也不是服务端 locale 存储:没有 profile 功能随
包发布(profile 槽是给有它的宿主留的),存储默认用宿主的浏览器
localStorage,可注入、尽力而为。

## 何时选用

凡是渲染 speed 组件的宿主都要用,凡是有自己用户文案的宿主也都要
用。所有组件包都经这个包的实例渲染文案,所以宿主启动时建一次实
例,渲染任何东西之前把各命名空间注册好。单语言产品也选它:对等检
查把缺翻译变成启动期错误,绝不会是静默的洞。

## 接线与最少使用

```ts
import { createI18n, switchLanguage } from '@speed/i18n'

const i18n = createI18n() // 协商起始语言,同步;实例可直接喂给 React
// 语言切换 UI:
await switchLanguage(i18n, 'en-US') // 持久化规范化的选择
```

```ts
import { registerNamespace } from '@speed/i18n'
import welcomeZh from './locales/welcome/zh-CN.json'
import welcomeEn from './locales/welcome/en-US.json'

registerNamespace(i18n, 'welcome', {
  'zh-CN': welcomeZh,
  'en-US': welcomeEn,
})
// 组件里:useTranslation('welcome') / t('greeting.hello')
```

react-i18next 的绑定从主入口再导出——`I18nextProvider`、
`useTranslation` 等等——宿主与组件包经同一个 `@speed` 包消费整片
面。lockstep 单版本发布钉死了模块同一性:任何宿主都不会同时有两份
react-i18next,这正是第三方组件里 `useTranslation` 安全的原因。

## 核心 API 与使用要点

- **`switchLanguage` 的存储参数是三态的**——`undefined` 用创建时
  绑定的存储,`null` 什么都不持久化,`StorageLike` 则持久化到该实
  例。手动语言切换 UI 要持久化(默认);宿主**应用服务端解析出的
  profile locale 时必须传 `null`**,否则写进手动槽的旧选择会在之后
  的访问里压过 profile 的每次变更。
- **存储按设计尽力而为**——写失败只告警,实例照常切换(而 promise
  被拒绝永远意味着切换没发生);创建时读抛错只当「没有存储的选择」,
  绝不导致创建失败。
- **复数形式是带后缀的叶子键**,对对等规则来说就是普通键:因为各
  资源束键集相同,zh-CN 也带着 `_one` 形式——只有 en-US 计数为 1
  时会选中它。
- **`muiLocaleFor`**(`@speed/i18n/mui-locale`)把活动语言映射成
  `createTheme` 要的 MUI locale 表;遇到未知标签直接抛错,不会静默
  让中文界面配英文 locale 文案,且按语言同一性稳定。子路径隔离保
  证 MUI 不进主入口的 import 图——没有 MUI 的消费者根本不会解析到
  它。
- **命名空间名是短键**——`[A-Za-z][A-Za-z0-9_-]*`。带作用域的
  npm 式名字如 `@speed/tokens` 会被拒绝:命名空间是宿主在
  `useTranslation('...')` 里要写的短键,不是包标识。

## 边界与注意

- **绝不渲染另一种语言的文字。**不要去配 fallback:实例被钉死
  不许跨语言回退,加载语言里缺的键渲染成键本身并触发处理器。未知
  *浏览器语言*落到 `en-US` 协商默认是另一条规则(一条记录在案、
  可覆盖的协商默认)——它不是翻译可以回退的许可证。
- **每个实例只注册一次**,绝不要在组件或 provider 里注册——重复
  注册守卫会抛错。注册之后才出现的缺口无法经本包的 API 制造:按
  设计不存在逐键删除。
- 在**裸 i18next 实例**上注册会被拒绝——`createI18n` 才是钉死受
  支持语言集与无回退选项的地方;合规实例没有别的造法。
- 空翻译在注册时被拒(它会渲染成沉默,和丢键无法区分);嵌套深于
  普通记录的层级同样被拒。
