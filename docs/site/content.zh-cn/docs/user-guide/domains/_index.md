# 领域指南

进入 speed 最快的路径:每个领域页把一个产品需求从头走到尾——涉及
哪些模块、最少集成步骤、示例,以及下一步去哪。

- [身份与访问](identity-access/)——登录、会话与权限(`authn`、`rbac`、
  `org`)。
- [多租户与组织](tenancy-and-org/)——租户解析与组织树。
- [数据与配置](data-and-config/)——数据模型、四数据域、动态配置。
- [计费与计量](billing-metering/)——用量计量、订阅计划、信用点、
  合规操作。
- [异步任务与通知](jobs-and-notifications/)——后台任务与消息面。
- [存储、分享与 AI](storage-sharing-and-ai/)——对象存储、公链分享、
  AI 网关。
- [可观测与运维](observability-and-ops/)——日志、指标、追踪、错误码
  处理。
- [前端搭建](frontend-building/)——组合 `@speed/*` npm 包。

逐模块完整参考——每个 Go 模块与 npm 包各有专页——见[模块参考](../modules/)。
