# 用户指南

用 speed 搭建你的 SaaS:挑你需要的模块,把它们组装进一个二进制,然后
完全拥有产物。这些指南面向在自己产品中**使用** speed 的 Go 模块与
npm 包的团队。

## 本栏的两种读法

- **按领域**——最快进入的方式。每个领域页把一个产品需求从头走到尾
  (身份与访问、多租户与组织、通知、计费、AI……):涉及哪些模块、最
  少集成步骤、示例,以及下一步去哪。先从[快速开始](/zh-cn/docs/user-guide/quickstart/)
  开始,再跟你的产品需要的领域走。
- **按模块**——完整参考。每个 Go 模块与 npm 包都有自己的页面:它做
  什么、何时选用、怎么接线、核心概念与 API 面、可运行示例,以及已
  知限制。

本栏左侧导航按模块依赖顺序排列:先是基础设施(`pkgcore`、`dbkit`
……),再是平台服务、身份与组织,然后是依赖图顶层的业务能力模块。
